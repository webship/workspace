# The logos of the platforms the step packs are for

The Extra steps panel (a project's Tests menu) shows them beside each `@webship-js/<name>-steps` pack, the
same files the docs cards on webship.co show. Each logo belongs to its project; `core/config/step-packs.json`
names the file of each pack.

- `aspnet-core` (the set's `dotnet`), `astro`, `codeigniter`, `craftcms`, `discourse`, `django`, `docusaurus`, `drupal`, `filament`, `flutter`, `gatsby`, `ghost`, `gitea` (the pack of Gitea and Forgejo), `hubspot`, `jira`, `joomla`, `laravel`, `magento`, `mautic`, `moodle`, `nextcloud`, `nextjs` (the set's `nextdotjs`), `spring-boot` (the set's `springboot`),
  `odoo`, `openproject`, `payload` (the set's `payloadcms`), `penpot`, `phpbb`, `plane`, `prestashop`, `roundcube`, `shopify`, `squarespace`, `strapi`, `svelte`, `symfony`, `typo3`, `uikit`, `vikunja`, `wagtail`, `webflow`, `woocommerce`, `wordpress` (`.svg`): Simple Icons
  16.37.0 (CC0-1.0), filled with the colour the set lists for the brand.
- `keycloak.svg`: Simple Icons 16.37.0, filled with the colour the set lists for the brand. Unlike most of the set,
  Simple Icons marks this icon as under the Linux Foundation's trademark usage guidelines rather than CC0-1.0; it is
  used only to name the platform the pack works with.
- `redmine.svg`: Simple Icons 16.37.0, filled with the colour the set lists for the brand. The set lists this icon
  under CC BY-SA 2.5, the Redmine logo's own licence (https://www.redmine.org/projects/redmine/wiki/logo); it is used
  only to name the platform the pack tests.
- `bootstrap.svg`: Simple Icons 16.37.0, filled with the brand colour `#7952B3`. The set lists this icon under the MIT
  licence (the Bootstrap project's).
- `mediawiki.svg`: the MediaWiki logo the 1.46.2 release ships (`resources/assets/mediawiki_compact.svg`),
  unmodified: by Serhio Magpie, under the Creative Commons Attribution-ShareAlike 4.0 licence (Simple Icons has no
  MediaWiki icon). MediaWiki and its logo are trademarks of the Wikimedia Foundation; it names the software the pack tests.
- `django-cms.png`: the favicon of the django CMS repository (`cms/static/cms/img/favicon.png`).
- `backdrop-cms.png`: the logo in the Backdrop CMS repository (`core/themes/seven/logo.png`).
- `diffy.svg`: the favicon of diffy.website.
- `bbpress.svg`: the mark bbPress 2.6.22 ships (`includes/admin/assets/icons/logo.svg`, GPL-2.0-or-later), filled
  black (Simple Icons has no bbPress icon).
- `buddypress.svg`: the BuddyPress mark WordPress 7.1.5 ships in its icon font (`buddicons-buddypress-logo` of
  `wp-includes/fonts/dashicons.svg`, GPL-2.0-or-later), filled black (Simple Icons has no BuddyPress icon).
- `learnpress.png`: the icon LearnPress 4.5.0 ships in its plugin (`assets/images/icon-128x128.png`, GPL-3.0),
  unmodified (Simple Icons has no LearnPress icon).
- `opencart.png`: the cart of the OpenCart logo the 4.1.0.4 release ships (`image/catalog/opencart-logo.png`,
  GPL-3.0), cut out of the wordmark and set on a square; the release's favicon (`image/catalog/opencart.ico`) is the
  same cart at 16 px (Simple Icons has no OpenCart icon).
- `leantime.png`: the app icon Leantime 3.17.0 ships (`public/assets/images/icon-192.png`, AGPL-3.0), unmodified
  (Simple Icons has no Leantime icon). Leantime and its logo are Leantime's; it names the software the pack tests.
- `kanboard.svg`: the icon Kanboard 1.2.58 ships (`assets/img/inkscape-optimized-icon.svg`, MIT), unmodified (Simple
  Icons has no Kanboard icon). Kanboard and its logo are Kanboard's; it names the software the pack tests.
- `wekan.png`: the app icon Wekan 13.33 ships (`public/android-chrome-192x192.png`, MIT), unmodified (Simple Icons has
  no Wekan icon). Wekan and its logo are Wekan's; it names the software the pack tests.

A pack with no logo here shows the one its own package ships (`assets/logo.svg` or `.png`), and a puzzle piece
when there is none.
