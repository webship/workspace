# The logos of the platforms the step packs are for

The Extra steps panel (a project's Tests menu) shows them beside each `@webship-js/<name>-steps` pack, the
same files the docs cards on webship.co show. Each logo belongs to its project; `core/config/step-packs.json`
names the file of each pack.

- `astro`, `codeigniter`, `craftcms`, `django`, `drupal`, `gatsby`, `ghost`, `hubspot`, `jira`, `joomla`, `laravel`, `magento`, `moodle`,
  `odoo`, `prestashop`, `shopify`, `squarespace`, `symfony`, `typo3`, `webflow`, `woocommerce`, `wordpress` (`.svg`): Simple Icons
  16.37.0 (CC0-1.0), filled with the colour the set lists for the brand.
- `bootstrap.svg`: Simple Icons 16.37.0, filled with the brand colour `#7952B3`. The set lists this icon under the MIT
  licence (the Bootstrap project's).
- `mediawiki.svg`: the MediaWiki logo the 1.46.2 release ships (`resources/assets/mediawiki_compact.svg`),
  unmodified: by Serhio Magpie, under the Creative Commons Attribution-ShareAlike 4.0 licence (Simple Icons has no
  MediaWiki icon). MediaWiki and its logo are trademarks of the Wikimedia Foundation; it names the software the pack tests.
- `django-cms.png`: the favicon of the django CMS repository (`cms/static/cms/img/favicon.png`).
- `backdrop-cms.png`: the logo in the Backdrop CMS repository (`core/themes/seven/logo.png`).
- `diffy.svg`: the favicon of diffy.website.

A pack with no logo here shows the one its own package ships (`assets/logo.svg` or `.png`), and a puzzle piece
when there is none.
